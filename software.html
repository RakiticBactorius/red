SOFTWARE

El software es un conjunto intangible de programas, instrucciones y datos que le indican a un dispositivo electrónico qué hacer y cómo hacerlo, permitiéndole ejecutar tareas específicas y funcionar. Se opone al hardware, que es la parte física del dispositivo. Los tipos principales de software son el software de sistema (como los sistemas operativos), el software de programación (herramientas para crear otros programas) y el software de aplicación (programas que realizan tareas para el usuario, como procesadores de texto o videojuegos).
